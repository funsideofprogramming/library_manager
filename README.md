# Library Manager

This is a little library manager I'm building in C to manage my personal library.

I started this project while learning C because I wanted to actually build something on my own instead of just watching tutorials and following along with whatever someone else was coding.

I already knew some C before starting this, but knowing how something works and actually using it to build a program are two different things lol.

## Why I'm Building This

I wanted something simple that I could actually use.

The idea is to have a program where I can keep track of my books, see what I've read, what I haven't read, and just manage my library without making things complicated.

I also wanted to challenge myself to build something without relying on a tutorial for every little thing.

## What I've Learned So Far

This project has taught me quite a bit about C, especially pointers and memory management.

I've been working with structs, pointers to pointers, dynamic memory allocation using `malloc`, `calloc`, and `realloc`, and freeing memory when I'm done with it.

Strings were probably one of the most interesting parts. I learned how to read user input character by character, resize memory when a string gets too long, and work with null terminators.

I also got more comfortable with functions, loops, arrays, and passing pointers around.

One thing I've realized is that understanding a concept while reading a book is completely different from trying to use it in an actual program. Sometimes something looks easy until you try implementing it yourself lol.

Debugging has been a big part of the process too. I've made some pretty dumb mistakes, spent time figuring out why something wasn't working, and learned a lot from fixing them.

## What It Can Do

Right now, the program lets me add books with their titles and authors, view my library, search for books by name, and keep track of which books I've read.

I can also change a book's reading status and see how many books I have or how many I've finished reading.

It's all running in the terminal for now, which is exactly what I wanted.

## What's Next

I'm still working on the project.

I want to add the ability to edit book information in case I make a typo, and implement file handling so my library doesn't disappear every time I close the program.

There are probably other things I'll add along the way as I learn more.

## Final Thoughts

This is one of my first projects that I've actually worked on without following a step by step tutorial.

It's nothing crazy, but I'm learning a lot more from building this than I would from just watching someone else code.

I'm keeping it on GitHub so I can look back at my progress and see how much I've improved.

Still got a lot to learn, but that's kinda the whole point.
